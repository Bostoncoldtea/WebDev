CSS

CSS is stands for cascading style sheets. So while HTML creates the elements on the page CSS is what styles it. It can help with the design and layout of the web page.

JavaScript is a coding language that allows to make the website or webpage manipulates HTML content, styles, and attributes

JavaScript is a programming language that is used to add interactivty.It manipulates the HTML content, styles, and attributes.What this means is that it allows for being able to click button and such.
